# JNTU C Lab check50 checks

Publish this directory as a public GitHub repository, e.g.:

`YOUR_ORG/jntu-c-lab-checks`

Students run:

`check50 YOUR_ORG/jntu-c-lab-checks/main/01-sum-of-digits`

and similarly for the other seven slugs.

These checks are designed as development feedback. Keep authoritative/hidden grading in Classroom 50.
